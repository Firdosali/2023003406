Vehicle Maintenance Scheduler

Approach:
Implemented the 0/1 Knapsack algorithm to maximize total vehicle impact score while staying within the mechanic-hour limit of each depot.

Mapping:
Duration -> Weight
Impact -> Value
MechanicHours -> Capacity

Implementation:
- Authentication completed successfully.
- Attempted integration with Depot and Vehicle APIs.
- API responses were handled using Python requests library.
- Dynamic Programming (Knapsack) used for optimization.
